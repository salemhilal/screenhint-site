Questions, bug reports, or ideas? Email [screenhint@salem.io](mailto:screenhint@salem.io).

If something isn't working, it helps to include which version of macOS you're on and which version of ScreenHint you have (you can find it in ScreenHint's About window). A screenshot or a short description of what you were doing when it happened goes a long way, too.
